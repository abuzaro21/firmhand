# AI disclosure

FIRMHAND was built with AI assistance. This page says which tools were used, for what, and what was checked.

## At runtime: no AI
The product makes **no model calls**. Sales, Operations and Finance are deterministic policy modules in `src/agents/`. A seed always produces the same week, and every decision is stored with the rule that produced it. There is no API key, no inference cost and no prompt to inject.

"Agent" here means an independent role runtime: its own inbox, memory, status and permissions, acting only through the command kernel. It does not mean a language model.

## While building it
| Tool | Model (as reported by its runtime) | Used for |
|---|---|---|
| Claude Code | Claude Opus 5.5 (`claude-opus-5-5`) | Architecture A, all code, tests, documents, the film pipeline, and fixes for review findings |
| OpenAI Codex CLI | `gpt-6.1-sol`, read from the CLI's own session header in each log | Architecture B, written without seeing A; eight read-only adversarial reviews and fix verifications (`docs/reviews/R1`–`R8`) |
| Kokoro-82M | open-weight TTS (Apache-2.0), run locally on the CPU | The film's narration voice |

Codex always ran with `-s read-only`. It changed no files; every fix was made by Claude and is covered by a regression test in `test/regressions.test.ts`. Review prompts and answers are in [`reviews/`](reviews/). [`reviews/PROVENANCE.md`](reviews/PROVENANCE.md) lists each run's model, sandbox and session id from the CLI header. The raw run logs are not published, because they contain unrelated files from the reviewer's machine. [`reviews/REVIEW-SUMMARY.md`](reviews/REVIEW-SUMMARY.md) maps each finding to its fix and test.

## Media
- **Product footage** in the film is a real Playwright capture of the running build. It is not generated or composited.
- **Narration** is synthetic (Kokoro-82M, voice `af_heart`). The end card says so.
- **Music bed** is a sine drone generated by ffmpeg in `film/build.mjs`.
- **Logo** is hand-specified SVG geometry (`ui/public/favicon.svg`), animated with CSS in `film/logo.mjs`. No image model was used.
- **Fonts** are Fraunces and Inter (SIL OFL), bundled through `@fontsource-variable`.

## Data
The company (Hearthbrew Coffee Gear), its 40 customers, 2 suppliers, products, orders and amounts are synthetic and generated from a seed. No real person, business, payment or customer is involved. The suppliers are labelled fictional in the product.

## What was not done
- No human has watched or listened to the film as a review step. Its checks are automated (`film/README.md`).
- The name FIRMHAND has not had a trademark search.
- The "operator" is a demo role bound to a browser cookie, not a verified human identity.
- Checksums compare replay with live state. They are not a signed or tamper-evident log.
