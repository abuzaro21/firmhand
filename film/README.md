# The FIRMHAND film

An 89.5-second film of the running product: 1920×1080, 30 fps, H.264 video with AAC stereo audio, English narration, burned-in captions and a soft caption track. It ends on the animated FIRMHAND logo.

- **Final file:** `firmhand-film.mp4`. It is attached to the [v1.0.0 release](https://github.com/abuzaro21/firmhand/releases/tag/v1.0.0) and is not committed to Git.
- **Captions:** [`firmhand-film.srt`](firmhand-film.srt)
- **Contact sheet:** [`contact-sheet.png`](contact-sheet.png)
- **Automated check report:** [`../docs/evidence/film-check.json`](../docs/evidence/film-check.json)

## What is real and what is synthetic
- **Real:** every product frame. `capture.mjs` starts the actual server with an in-memory SQLite store and drives one continuous browser session with Playwright, using real clicks. Agent actions, KPI changes, the approvals, the crash, the recovery, the replay and the comparison table are all live product state. Nothing is mocked, composited or sped up. The edit only cuts between scenes of that one session.
- **Synthetic:** the narration voice is Kokoro-82M (open weights, Apache-2.0), run locally on the CPU. The music bed is a sine drone generated by ffmpeg. The company and all its data are fictional. The end card says so.
- **Logo:** rendered frame by frame from the product's own vector mark (`ui/public/favicon.svg` geometry) by `logo.mjs`.

## Storyboard
Times are narration starts in the final cut.

| At | Scene | What you see (real capture) | Narration |
|---:|---|---|---|
| 0:00 | title | The cockpit on Day 1, before anything runs | This is FIRMHAND. A small company run by three agents, one shared ledger, and you. |
| 0:06 | agents | The run starts at 3×. Sales, Operations and Finance receipts fill their own lanes | Each agent has its own inbox, rules and permissions; they meet only in the shared records |
| 0:19 | approval | The run stops on its own. The 18% discount request with evidence, bound records and hash. The operator approves | Sales may give ten percent; the request waits for me, bound by a hash |
| 0:31 | shock | Day 3 grinder surge and supplier delay. Incidents, the expedite purchase order, Sales re-promising | Nobody asks me. Operations sizes an expedite, Finance funds it inside budget, Sales re-promises |
| 0:45 | crash | Day 5. Operations faulted, Finance's watchdog incident, spend freeze, the restart request | Finance notices because work stopped moving, and asks me before anything restarts |
| 0:57 | recover | The operator approves the restart. Operations dispatches the half-packed parcels and catches up | Operations finishes its half-packed parcels exactly once |
| 1:04 | kpi | The week is complete. Recognised revenue opens its journal lines | Every number opens the records behind it |
| 1:11 | proof | Replay with the side-effect digests, then the managed-vs-naive comparison | Any day replays from the event log alone; against a naive company it keeps every customer |

The closing claim ("keeps every customer") is about the comparison shown on screen: seed 7, where FIRMHAND loses 0 customers in both scenarios and the naive company loses 8 and 5. See [`../docs/evidence/comparisons.md`](../docs/evidence/comparisons.md).

## Rebuild it
Run from the repository root, with ffmpeg on the PATH.
```bash
npm ci && npm run build
py -3.11 -m venv film/.venv
film/.venv/Scripts/python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
film/.venv/Scripts/python -m pip install "kokoro>=0.9.4" soundfile
film/.venv/Scripts/python film/tts.py   # narration -> film/out/audio
node film/capture.mjs                   # real session -> film/out/raw/session.webm
node film/build.mjs                     # edit, mix, captions, logo -> film/out/firmhand-film.mp4
node film/check.mjs                     # automated checks -> film/out/check/report.json, film/contact-sheet.png
```

## Verification
`check.mjs` measures these and all of them pass:
- duration (89.47 s), resolution, frame rate and frame count;
- codecs, and that video and audio both decode;
- no black frames;
- no clipping (true peak −4.3 dBTP);
- loudness (about −17 LUFS integrated);
- caption timing: monotonic, inside the film, and no cue during silence;
- captions burned into the picture, measured against the un-captioned render;
- the last frame matches the logo master, and the last 2 s are stable.

These are machine measurements only. **No human has watched or listened to this film as a review step.** Pacing, voice quality and legibility have not been judged by a person.
